# 📧 Outlook Drafts - מערכת שליחת קורות חיים

אפליקציית Web שמאפשרת למגייסים בחברות השמה לפתוח טיוטות מייל ב-Outlook באופן אוטומטי.

## 🎯 מטרת הפרויקט

המערכת מאפשרת למשתמש למלא טופס באפליקציה ולפתוח טיוטות מייל מרובות ב-Outlook המקומי, כאשר כל טיוטה מכילה:
- נושא המייל
- נמען ספציפי
- גוף ההודעה
- קובץ מצורף (קורות חיים)

**חשוב:** המערכת **לא שולחת** את המיילים אוטומטית - היא פותחת טיוטות כדי שהמשתמש יוכל לבדוק, לערוך ולשלוח בעצמו.

## 🛠️ טכנולוגיות

### Backend:
- **Python 3.x**
- **Flask** - שרת Web
- **pywin32 (win32com)** - התממשקות ל-Outlook
- **pythoncom** - ניהול COM threading

### Frontend:
- **HTML5** - מבנה הטופס
- **CSS3** - עיצוב
- **JavaScript** - תקשורת עם השרת

## 📦 התקנה

### דרישות מקדימות:
- Windows OS
- Python 3.7+
- Microsoft Outlook מותקן ומוגדר עם חשבון מייל

### שלבי התקנה:

1. **שכפול הפרויקט:**
```bash
git clone https://github.com/YOUR_USERNAME/outlook-drafts-project.git
cd outlook-drafts-project
```

2. **התקנת תלויות:**
```bash
pip install flask pywin32
```

3. **הרצת השרת:**
```bash
python app.py
```

4. **פתיחת הדפדפן:**
```
http://localhost:5000
```

## 🔧 איך זה עובד?

### ארכיטקטורה:

1. **Frontend (דפדפן):**
   - משתמש מזין נתונים בטופס HTML
   - JavaScript שולח POST request לשרת Flask

2. **Backend (Flask):**
   - מקבל את הנתונים מהטופס
   - מפצל את רשימת הנמענים
   - שומר את הקובץ המצורף זמנית
   - קורא לפונקציה שיוצרת טיוטות

3. **COM Automation (win32com):**
   - מתחבר ל-Outlook המקומי דרך COM
   - יוצר טיוטה נפרדת לכל נמען
   - מצרף את הקובץ לכל טיוטה
   - פותח את החלונות ב-Outlook

### למה לא mailto:?

הפרוטוקול `mailto:` לא מספיק כי:
- ❌ לא תומך בצירוף קבצים
- ❌ מוגבל באורך URL (~2000 תווים)
- ❌ לא נותן שליטה על הטיוטות
- ❌ לא יכול ליצור טיוטות נפרדות לכל נמען

**win32com** הוא הפתרון היחיד שמאפשר שליטה מלאה על Outlook מקומי.
